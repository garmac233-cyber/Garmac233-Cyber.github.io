# 无界 WUJIE · 空间作品与服务

基于已确认的 V10，整理于 2026-11-11。纯静态 HTML、CSS、JavaScript，无需安装依赖或运行构建。

## 网站内容

- 11 个空间项目及精选照片，桌面高清图与手机适配图。
- 六个服务阶段、自动图像演示、设计周期与落地工期。
- 公司、团队及深圳 / 福建办公地点地图。
- 居住问答、偏好结果与设计沟通摘要导出。

## Cloudflare Pages

连接此 GitHub 仓库，选择以下配置：

| 配置 | 值 |
|---|---|
| 生产分支 | `main` |
| 框架预设 | `None` |
| 构建命令 | `exit 0` |
| 输出目录 | `public` |
| 根目录 | 默认留空 |

发布成功后使用 Cloudflare 分配的 `pages.dev` 地址。推送到 `main` 后自动更新。网站源文件全部位于 `public/`；该目录也可单独用于静态托管。

## 本地查看与维护

可直接打开 `public/index.html`。地图需要联网。需要通过本地网址查看时，在 `public/` 目录运行任意静态文件服务器。

作品内容在 `public/content.js` 与 `public/project-photos.js`；服务在 `public/process.js`；关于页在 `public/about.js`；照片位于 `public/assets/`。

问答与合作需求保存在访问者自己的浏览器中，下载由浏览器完成，不自动上传到服务器。部署时无需配置数据库或密钥。地图使用 OpenFreeMap / OpenStreetMap 在线数据，保留相应署名。

本仓库只含网站发布内容，不包含原始资料、客户答卷、内部研究或其他托管服务的凭据。品牌、项目图片与人物内容保留原有权利；随附第三方库遵循各自许可。
